# One-line lab, licking itself — for the 4" hoop

**Use `lab-lick-pattern-FINAL.svg`** (preview: `lab-lick-pattern-FINAL.png`).
One continuous line, sized for a 4-inch hoop. Green dot = where the thread
starts, red dot = where it ends (at the tongue — the punchline stitches last).
The dashed circle is the hoop edge, not part of the pattern.

`v1` and `v2` are failed drafts — kept on purpose (they mark the dead ends:
the curled-sitting pose buries the head inside the body mass and stops
reading as a dog). Don't stitch those unless you want an abstract beetle.

Transfer: print the SVG at 100%, then Stick'n Stitch it, or tape to a bright
window and pencil-trace onto the fabric.
